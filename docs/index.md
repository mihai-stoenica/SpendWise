# SpendWise Documentation

Welcome to the **SpendWise** documentation.

## Architecture

- **UI (`spendwise.ui`)**: CustomTkinter views.
- **Services (`spendwise.services`)**: Business logic for profiles, transactions, categories, budgets, alerts, forecasts, exports, and reports.
- **Repositories (`spendwise.repositories`)**: SQLite database access and schema management.
- **ML (`spendwise.ml`)**: Category suggestion and spending forecast interfaces and implementations.
